编写数字取证工具，核查来自独立采集器的分区镜像能否对应同一处置时间。用虚构介质、采集可信标记和区块摘要建模，不读取实际磁盘或个人数据。每个区块有初始摘要，写入事务列出全部被修改区块及修改后的摘要。同一采集器观测到的事务按本地日志序号排序，跨采集器因果关系和原子多区块事务由输入声明。取证时刻是满足偏序的全局前缀，纳入事务须纳入其全部先决项，一次事务的所有区块同时可见。任两个写同一区块的事务必能由因果关系排出先后，违反此条件的输入报结构错误。镜像分片声明采集器、块域、每块观察摘要，以及全局切片必须包含和排除的证据屏障；未采集的区块不施加摘要约束。所有分片只允许使用满足全部屏障的同一切片；禁止把每片的不同可行时刻拼成整盘证据。

reconstruct 判断整组分片是否能来自同一切片。输出最少已纳入事务的切片，同数时取升序事务 ID 列表中字典序最小者，并给每个已采集块的最后写入者或初始来源。块摘要曾被改回原值时仍须保留最后写入者。无解给一个可复现的包含极小冲突集。把整片作为单位，按分片 ID 降序尝试移除，若移除后依然无解则永久移除。事务日志和既定偏序始终保留。compare 可在见证区块集上核查两个可能切片。对每一块分别报告可出现的来源和摘要，并另求同一个可行切片下最多有多少见证块与指定保全镜像不一致，按事务数及 ID 列表决胜，不能将各块单独可能的差异直接相加。

suspect 在已有分片上推断哪组采集器可能受过污染。输入为每台采集器指定隔离代价，并允许指定不得丢弃的固定证据。一个采集器被隔离后只去除该采集器的可撤分片，任何固定证据继续生效。求能让剩余证据来自同一切片的最小成本隔离方案，其次最少台数及 ID 决胜。返回未隔离证据的切片和逐片解释，用小规模独立穷举核对联合选择。验证本地可解释但合起来冲突、跨区事务的半截镜像、重回原摘要、新证据使可行来源收缩、删除廉价采集器却无解、以及同一个历史切片不能同时实现逐块最大差异。支持 80 个事务、30 个分片与 16 个可隔离采集器，不得遍历所有完整事件排列。README 说明搜索共享与剪枝如何保持最优性。

交付可在 Windows 原生 Python 3.12 上直接运行的空仓库实现，仅用标准库及 CPU。命令行约定 python -m solution <命令> CASE.json，结构错误提供字段位置与错误码，结果以确定性的 UTF-8 JSON 写到标准输出。提供虚构可运行样例、含完整输入输出定义和复现命令的 README，以及 python -m unittest discover -s tests -v 能运行的断言测试。
